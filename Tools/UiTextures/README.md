# UI textures

`python make_ui_textures.py` (numpy + Pillow) régénère les textures du thème « aurore » dans
`Assets/UI/Textures` : `Panel.png` (dégradé des panneaux), `Aurora.png` (fond des grandes fenêtres et de la
boutique), `Divider.png`, `ScrollTrack.png` et `ScrollThumb.png` (barres de défilement, 9-slice). Contenu
original généré, aucune licence tierce.
