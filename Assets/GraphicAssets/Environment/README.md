# Environnement de l'arène

- `Kenney/Nature` : **Nature Kit** de Kenney (www.kenney.nl), licence **CC0** (voir `License.txt`).
  Seuls les modèles utilisés sont copiés ; leurs matériaux sont remplacés à l'import par la palette
  naturelle de `Materials/Nature_*.mat` (`EditorTools.ArenaSetup`).
- `Ground` : sol peint de la clairière, sol de forêt et texture de détail, générés par
  `Tools/SpriteBaking/paint_ground.py` (bruit procédural, aucun asset tiers).
- `ArenaFloor.asset` : disque marchable (rayon 40) dont est cuit le NavMesh.
